## Описание задачи

Робот автоматически формирует оборотно-сальдовую ведомость (ОСВ) в 1С через веб-интерфейс браузера. При запуске он читает параметры из конфигурационного файла `config.json`, авторизуется в 1С, переходит к форме ОСВ, вводит период и организацию, формирует отчёт и сохраняет результат в указанную папку.

### Алгоритм работы робота

Робот работает в несколько этапов:

1. Чтение конфигурации.
   Робот читает параметры из `resource/config.json`: период, организация, формат и путь сохранения.

2. Авторизация в 1С.
   Открывает браузер Chrome, переходит по BASE_URL, вводит логин и пароль, нажимает «Войти».

3. Навигация к ОСВ.
   Переходит в раздел «Отчёты» → «Оборотно-сальдовая ведомость».

4. Ввод параметров.
   Вводит период и организацию из конфига.

5. Формирование и сохранение.
   Нажимает «Сформировать», сохраняет результат в файл.

## Входные параметры

```json
{
  "report_type": "osv",
  "period_start": "01.03.2025",
  "period_end": "31.03.2025",
  "organization": "Магазин №23",
  "output_path": "resource/output",
  "output_format": "xlsx",
  "file_name": "osv_march"
}
```

### `report_type`

Тип отчёта. Поддерживается:
- `osv` — оборотно-сальдовая ведомость

### `period_start` и `period_end`

Период отчёта в формате `ДД.ММ.ГГГГ`.

Пример:
```
"period_start": "01.03.2025"
"period_end": "31.03.2025"
```

### `organization`

Наименование организации точно как в 1С.

Пример:
```
"organization": "Магазин №23"
```

### `output_format`

Формат сохранения результата:
- `xlsx` — Excel файл
- `pdf` — PDF через печать

### `file_name`

Имя файла без расширения.

## Требования

- Puzzle RPA Studio 3.0.3
- Google Chrome
- Доступ к веб-интерфейсу 1С (BASE_URL, LOGIN, PASSWORD — выданы организаторами)

## Установка и запуск

1. Распакуйте архив с проектом.
2. Откройте проект в Puzzle RPA Studio (Проект → Открыть проект).
3. Отредактируйте `resource/config.json` — укажите период и организацию.
4. Запустите робота: откройте `process/main` и нажмите F5.
